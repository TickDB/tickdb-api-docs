## 套餐權限

| 套餐 | 可用 |
|---|:---:|
| 免費版 | ❌ |
| 基礎版 | ✅ |
| 專業版 | ✅ |
| 全量套餐（A 股、港股、美股） | ✅ |
| 企業版 | ✅ |

## 注意事項
- 買盤（bids）按價格降序排列
- 賣盤（asks）按價格升序排列
- 返回檔位數量由相應市場實際支持的深度決定
- 時間戳單位為毫秒（UTC）

## 支持的市場

| 市場 | 示例 | 每側盤口檔位 |
|------|------|--------------|
| 美股 | AAPL.US、TSLA.US、MSFT.US | 1檔 |
| 港股 | 700.HK、9988.HK、3690.HK | 10檔 |
| A股 | 600519.SH、000001.SZ、920186.BJ | 5檔 |
| 中國期貨 | BU2609、RB8888、AP8888 | 1檔 |
| 香港期貨 | HSI8888、MHI8888、HTI8888 | 10檔 |
| 加密貨幣 | BTCUSDT、ETHUSDT、ADAUSDT、OKBUSDT | 最高1000檔 |

表中為每側盤口最高支持檔位。不同產品支持的深度可能不同；休市、流動性不足或部分檔位無報價時，實際返回檔位可能少於表中數量。

## 請求參數

| 參數名 | 是否必須 | 描述 |
|--------|----------|------|
| symbol | 是 | 交易產品代碼 |
| type | 否 | 產品類型，可選。代碼無歧義時無需傳遞；若返回 `AMBIGUOUS_SYMBOL` 錯誤，按提示傳入對應值即可。可選值：`stock`、`indices`、`crypto`、`forex`、`futures` |

## 返回字段說明

| 字段 | 說明 |
|------|------|
| symbol | 交易產品 |
| type | 產品類型 |
| timestamp | 數據時間戳（毫秒，UTC） |
| bids | 買盤數組，每個元素為 [價格, 數量] |
| asks | 賣盤數組，每個元素為 [價格, 數量] |
