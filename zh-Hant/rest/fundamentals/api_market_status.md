## 套餐權限

| 套餐 | 可用 |
|---|:---:|
| 免費版 | ❌ |
| 基礎版 | ✅ |
| 專業版 | ✅ |
| 全量套餐（A 股、港股、美股） | ✅ |
| 企業版 | ✅ |

## 注意事項

- 這是全局接口，不接受 `market` 或 `symbol` 參數；狀態隨交易時段變化。

## 支持的市場

| 市場 | 示例 |
|---|---|
| 美股 | US |
| 港股 | HK |
| A股 | CN |

## 請求參數

該接口不需要查詢參數。

## 請求示例

```bash
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://api.tickdb.ai/v1/fundamentals/market/status"
```

## 返回字段說明

以下列出 `data` 中的字段；外層 `code=0` 表示成功。

| 字段 | 說明 |
|------|------|
| markets | 各市場交易狀態列表。 |
| └─ market | 市場代碼。 |
| └─ market_time | 該市場的當前時間，RFC 3339 日期時間字符串，包含時區信息。 |
| └─ trade_status | 交易狀態代碼。 |

返回 `CN`、`HK`、`US` 三個市場的市場時間和交易狀態。

### `trade_status` 狀態碼

不同市場只會返回適用的狀態。常見及特殊交易階段的代碼如下：

| 市場 | 狀態碼 | 含義 |
|------|-------:|------|
| CN、HK | `101` | 開市前清算 |
| CN、HK | `102` | 開盤集合競價 |
| CN、HK | `105` | 正常交易 |
| CN、HK | `106` | 午間休市 |
| CN、HK | `107` | 收盤集合競價 |
| CN、HK | `108` | 已收市 |
| CN | `120` | 盤後固定價格交易 |
| CN、HK | `121` | 半日市收市 |
| CN、HK | `122` | 特殊情況下尚未開市 |
| CN、HK | `123` | 盤中臨時休市 |
| US | `201` | 盤前交易 |
| US | `202` | 正常交易 |
| US | `203` | 盤後交易 |
| US | `204` | 已收市 |
| US | `205` | 暫停交易 |
| US | `206` | 開市前清算及盤前時段 |
| US | `207` | 夜盤交易 |
| US | `209` | 盤前清算 |
| US | `210` | 盤後清算 |
