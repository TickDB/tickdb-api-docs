## 套餐權限

| 套餐 | 可用 |
|---|:---:|
| 免費版 | ✅ |
| 基礎版 | ✅ |
| 專業版 | ✅ |
| 全量套餐（A 股、港股、美股） | ✅ |
| 企業版 | ✅ |

## 注意事項
- 日期格式必須為 YYYYMMDD（如：20260201）
- 單次查詢的日期範圍最多為 31 天
- 開始日期必須在最近一年範圍內
- 返回的交易日不包括週末和節假日
- 市場代碼不區分大小寫

## 支持的市場

| 市場 | 示例 |
|---|---|
| 美股 | US |
| 港股 | HK |
| A股 | CN |

## 請求參數

| 參數名 | 是否必須 | 描述 |
|--------|----------|------|
| market | 是 | 市場代碼，可選值：`US`、`HK`、`CN` |
| beg_day | 是 | 開始日期，格式：YYYYMMDD，必須在最近一年範圍內 |
| end_day | 是 | 結束日期，格式：YYYYMMDD；與開始日期的範圍最多為 31 天 |

## 返回字段說明

| 字段 | 說明 |
|------|------|
| market | 市場代碼 |
| trade_days | 全日交易日列表，使用 YYYYMMDD 格式 |
| half_trade_days | 半日交易日列表（僅半天交易），使用 YYYYMMDD 格式 |
