歡迎使用 **TickDB 在線文檔**。

TickDB 是一個**面向開發者的統一即時行情數據 API**，透過單一連線即可存取多個金融市場的即時與歷史行情數據，幫助你避免管理多個資料來源與協議的複雜性，專注於產品與策略本身。

---

## 什麼是 TickDB？

TickDB 專為需要**可靠、低延遲、可長期依賴**行情數據的開發者所構建。

透過 **一次接入（one connection）**，即可無縫存取外匯、貴金屬、指數、美股、港股、A 股、期貨與加密貨幣等市場的行情資料。

TickDB 支援多種數據形式，包括 **tick 級成交數據、盤口深度（Order Book）、K 線（Candlestick）與全量市場行情**，並提供 **財務與基本面數據、財經日曆與市場資訊**。可透過 **REST API 與 WebSocket** 接入，適用於量化交易、即時行情系統、基本面研究、交易平台與資料分析等場景。

---

## 核心特性

- **統一接入**  
  一套 API 覆蓋多個市場與資產類別

- **即時數據**  
  基於 WebSocket 的串流推送，適用於即時行情場景

- **全量行情**
  覆蓋A股、港股和美股；單次 REST 請求即可取得指定市場的完整行情快照，一次 WebSocket 訂閱即可持續接收該市場全部標的的即時行情更新

- **多市場支援**  
  外匯、貴金屬、指數、美股、港股、A 股、期貨、加密貨幣

- **財務與基本面**
  提供公司資料、財務報表、估值、行業、分紅和股東持倉等數據

- **財經日曆**
  按財報、股息、拆股、新股及其他事件分類查詢

- **市場資訊**
  提供市場狀態、交易時段、交易日曆和個股新聞

- **開發者友好**  
  REST API + WebSocket，文件完整、範例清晰

- **AI 友好**  
  提供即時行情、財務與基本面、財經日曆與市場資訊等結構化數據輸入，便於 AI 開展公司分析、市場監控、事件追蹤與研究輔助；支援 Skill、MCP、CLI 多種接入方式

## AI 整合

TickDB 提供三檔 AI 原生接入方式，從零配置對話到終端自動化全覆蓋。

### Skill

**對話即用，零配置**

透過 [ClawHub](https://clawhub.com) 一鍵安裝，任意 LLM 即可調用 TickDB 行情數據。

```bash
npx clawhub@latest install tickdb-market-data
```

- 零註冊自動試用
- 72 核心品種免費
- 任意 LLM 通用

### MCP

**永久整合，一次配置**

透過 Hosted MCP Server 接入，相容 Claude Code、Cursor、Kiro、Zed 等所有 MCP 客戶端。

配置示例（以 Claude 為例，路徑：`~/.claude/settings.json`）：

```json
{
  "mcpServers": {
    "tickdb": {
      "type": "http",
      "url": "https://mcp.tickdb.ai/",
      "headers": {
        "X-TickDB-Key": "<YOUR_API_KEY>"
      }
    }
  }
}
```

- Hosted mcp.tickdb.ai，無需自部署
- HTTPS + Header 鑑權
- 相容所有 MCP 協議客戶端
- 提供 13 個工具，與 REST API 端點一一對應

### CLI

**終端 & AI Agent 就緒**

全域安裝後即可在終端直接查詢行情，也適合 Agent 透過 bash-tool 調用。

```bash
npm install -g tickdb
tickdb config set-key YOUR_API_KEY
tickdb ticker BTCUSDT,XAUUSD,AAPL.US
```

- JSON / 表格雙輸出
- 16 個原生命令
- Bash-tool 友好，適合 Agent 調用

### llms.txt

**為 AI 提供文檔上下文**

如需讓 AI 助手了解 TickDB 文檔，可向其提供以下地址：

```text
https://docs.tickdb.ai/llms.txt
```

如需包含全部頁面正文的完整版本，請使用：

```text
https://docs.tickdb.ai/llms-full.txt
```

詳細資訊請訪問 [TickDB AI 接入](https://tickdb.ai/ai-tools)。

## 典型使用場景

- **量化交易**  
  作為策略與算法系統的即時行情數據來源

- **行情看板**  
  即時價格顯示、資產與投資組合監控

- **交易應用**  
  建構類似 TradingView 的行情介面與圖表系統

- **數據分析與回測**  
  歷史行情分析、策略研究與回測

- **基本面研究**
  結合財務報表、估值、行業和股東持倉進行公司分析

- **市場監控**
  利用全量行情、新聞和財經日曆追蹤市場變化與重要事件

- **金融服務整合**  
  整合至既有交易平台或金融基礎設施

## REST API

### 通用行情接口
- **可用交易品種** - 查詢支持的交易品種
- **行情快照** - 即時行情快照
- **K 線查詢** - 按週期和時間範圍查詢 K 線數據
- **實時 K 線** - 當前週期正在形成的 K 線數據
- **盤口深度** - 即時買賣盤口數據
- **逐筆成交** - 逐筆成交記錄

### 股票市場接口

#### 全量行情
A股、港股和美股全市場行情快照

#### 個股行情與指標
股票資訊、當日分時、綜合指標和資金流向

#### 公司概況
公司資料、高管董事和營收構成

#### 財務報表
近期、年度和 TTM 財務數據及字段字典

#### 估值與行業
最新估值、歷史估值、同行比較和行業數據

#### 分紅與公司行動
分紅、股息 TTM、股票回購和公司行動

#### 股東與機構持倉
股東結構、股東持倉和持股基金

#### 財經日曆
財報日曆、股息日曆、拆股日曆、新股日曆及其他日曆

#### 市場資訊
市場狀態、交易時段、交易日曆和個股新聞
