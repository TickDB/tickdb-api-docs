## v1.0.3 (2026-09-21)

### 新增功能

- 新增財務與基本面接口文檔，涵蓋公司概況、主營構成、財務報表、估值與行業、分紅與公司行動、股東與機構持倉、市場資訊與日曆。
- 新增 A 股、港股和美股全量行情：REST API 單次請求可取得指定市場的完整行情快照，WebSocket 單次訂閱可持續接收該市場全部標的的即時行情更新。
- 新增 K 線復權因子接口及 JavaScript 計算範例，適用於基於不復權 K 線動態生成前復權或後復權數據。
- 增加對香港股票期貨和金融期貨的支援。

## v1.0.2 (2026-07-16)

### 新增功能

- 產品查詢、REST 行情接口和 WebSocket 頻道新增中國期貨支持，產品類型使用 `type=futures`。
- 新增期貨持倉相關字段：K 線 `open_interest`，成交數據 `open_interest_change` 和 `position_effect`。

## v1.0.1 (2026-03-13)

### 新增功能

- **新增股票市場專屬接口**
  - 當日分時數據接口
  - 股票詳細信息接口
  - 交易時段查詢接口
  - 交易日曆查詢接口
  - 市場指標數據接口
  - 資金流向數據接口

### 重要改進

- **WebSocket 文檔重構**
  - 新增 ping/pong 心跳機制說明
  - 更新 ticker 頻道消息格式（按市場類型區分字段）
  - 修正 trade 頻道響應格式（包含 trades 數組）
  - depth 頻道新增 A 股支持

- **文檔內容優化**
  - 重新組織 REST API 導航結構
  - 完善所有接口的請求參數和返回字段說明
  - 更新支持市場標註和示例
  - 統一術語翻譯
  - 優化入門指南和數據規範

## v1.0.0 (2026-01-15)

### 首次發布

提供核心 REST API 和 WebSocket 即時訂閱，覆蓋外匯、貴金屬、指數、美股、港股、A 股、加密貨幣市場。

- **REST API 接口**
  - 交易品種查詢
  - 行情快照
  - K 線查詢
  - 實時 K 線
  - 訂單簿
  - 最近成交
  - K 線週期查詢

- **WebSocket 頻道**
  - ticker 頻道
  - depth 頻道
  - trade 頻道
