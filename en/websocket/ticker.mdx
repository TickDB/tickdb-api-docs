## Supported Markets

Supported markets: Forex, Metals, Indices, US Stocks, HK Stocks, A-Shares, China Futures, Hong Kong Futures, Crypto

## Subscribe

```json
{
  "cmd": "subscribe",
  "data": {
    "channel": "ticker",
    "symbols": ["AAPL.US", "BTCUSDT"]
  }
}
```

> `type` applies to every symbol in that subscription. Omit it when subscribing to mixed product types. If a symbol is ambiguous, split the request by product type and pass the corresponding value.

## Unsubscribe

```json
{
  "cmd": "unsubscribe",
  "data": {
    "channel": "ticker",
    "symbols": ["AAPL.US"]
  }
}
```

### Fields

The `24h` suffix does not mean a rolling 24-hour window in every market. Crypto usually uses a rolling 24-hour window; stocks and futures usually use the current trading day or session. Except for `symbol`, `last_price`, and `timestamp`, fields depend on the product and data availability.

| Field | Type | Description | Markets |
|------|------|-------------|---------|
| symbol | string | Trading symbol | All |
| name | string | Product name, when available | Some products |
| type | string | Product type | All |
| category | string | Product category, when available | A-share market products |
| last_price | string | Latest price | All |
| timestamp | int | Unix timestamp in milliseconds | All |
| open | string | Opening price, when statistics are available | Stocks, futures, crypto, and others |
| prev_close | string | Previous close or reference price for the statistics window, when available | Stocks, futures, crypto, and others |
| ask_price | string | Best ask, when quotes are available | Forex, metals, futures, and others |
| bid_price | string | Best bid, when quotes are available | Forex, metals, futures, and others |
| spread | string | Bid-ask spread, when available | Forex, metals |
| volume_24h | string | Trading volume; see the statistics window above | Stocks, futures, crypto |
| quote_volume_24h | string | Turnover over the same window as `volume_24h`, when available | Stocks, crypto, and others |
| high_24h | string | High price over the same window as `volume_24h` | Stocks, futures, crypto |
| low_24h | string | Low price over the same window as `volume_24h` | Stocks, futures, crypto |
| price_change_24h | string | Price change over the same window as `volume_24h`, when available | Stocks, futures, crypto |
| price_change_percent_24h | string | Price change percentage, when available | Stocks, futures, crypto |
| trade_session | string | Extended session: `pre_market`, `post_market`, or `overnight` | US stocks in extended hours |
| quote_volume | string | Turnover in the current extended session, when available | US stocks in extended hours |
