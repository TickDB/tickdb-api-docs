Use this channel to check that the connection remains available. Send `ping` and the server replies with `pong`. `data.timestamp` is a Unix timestamp in milliseconds.

## Send

```json
{"cmd":"ping"}
```

## Response

```json
{"cmd":"pong","code":0,"message":"pong","data":{"timestamp":1768976158541}}
```
