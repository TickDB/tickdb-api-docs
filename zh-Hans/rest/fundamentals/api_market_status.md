## 套餐权限

| 套餐 | 可用 |
|---|:---:|
| 免费版 | ❌ |
| 基础版 | ✅ |
| 专业版 | ✅ |
| 全量套餐（A 股、港股、美股） | ✅ |
| 企业版 | ✅ |

## 注意事项

- 这是全局接口，不接受 `market` 或 `symbol` 参数；状态随交易时段变化。

## 支持的市场

| 市场 | 示例 |
|---|---|
| 美股 | US |
| 港股 | HK |
| A股 | CN |

## 请求参数

该接口不需要查询参数。

## 请求示例

```bash
curl -H "X-API-Key: YOUR_API_KEY" \
  "https://api.tickdb.ai/v1/fundamentals/market/status"
```

## 返回字段说明

以下列出 `data` 中的字段；外层 `code=0` 表示成功。

| 字段 | 说明 |
|------|------|
| markets | 各市场交易状态列表。 |
| └─ market | 市场代码。 |
| └─ market_time | 该市场的当前时间，RFC 3339 日期时间字符串，包含时区信息。 |
| └─ trade_status | 交易状态代码。 |

返回 `CN`、`HK`、`US` 三个市场的市场时间和交易状态。

### `trade_status` 状态码

不同市场只会返回适用的状态。常见及特殊交易阶段的代码如下：

| 市场 | 状态码 | 含义 |
|------|-------:|------|
| CN、HK | `101` | 开市前清算 |
| CN、HK | `102` | 开盘集合竞价 |
| CN、HK | `105` | 正常交易 |
| CN、HK | `106` | 午间休市 |
| CN、HK | `107` | 收盘集合竞价 |
| CN、HK | `108` | 已收市 |
| CN | `120` | 盘后固定价格交易 |
| CN、HK | `121` | 半日市收市 |
| CN、HK | `122` | 特殊情况下尚未开市 |
| CN、HK | `123` | 盘中临时休市 |
| US | `201` | 盘前交易 |
| US | `202` | 正常交易 |
| US | `203` | 盘后交易 |
| US | `204` | 已收市 |
| US | `205` | 暂停交易 |
| US | `206` | 开市前清算及盘前时段 |
| US | `207` | 夜盘交易 |
| US | `209` | 盘前清算 |
| US | `210` | 盘后清算 |
