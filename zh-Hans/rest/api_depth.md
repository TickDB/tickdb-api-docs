## 套餐权限

| 套餐 | 可用 |
|---|:---:|
| 免费版 | ❌ |
| 基础版 | ✅ |
| 专业版 | ✅ |
| 全量套餐（A 股、港股、美股） | ✅ |
| 企业版 | ✅ |

## 注意事项
- 买盘（bids）按价格降序排列
- 卖盘（asks）按价格升序排列
- 返回档位数量由相应市场实际支持的深度决定
- 时间戳单位为毫秒（UTC）

## 支持的市场

| 市场 | 示例 | 每侧盘口档位 |
|------|------|--------------|
| 美股 | AAPL.US、TSLA.US、MSFT.US | 1档 |
| 港股 | 700.HK、9988.HK、3690.HK | 10档 |
| A股 | 600519.SH、000001.SZ、920186.BJ | 5档 |
| 中国期货 | BU2609、RB8888、AP8888 | 1档 |
| 香港期货 | HSI8888、MHI8888、HTI8888 | 10档 |
| 加密货币 | BTCUSDT、ETHUSDT、ADAUSDT、OKBUSDT | 最高1000档 |

表中为每侧盘口最高支持档位。不同产品支持的深度可能不同；休市、流动性不足或部分档位无报价时，实际返回档位可能少于表中数量。

## 请求参数

| 参数名 | 是否必须 | 描述 |
|--------|----------|------|
| symbol | 是 | 交易产品代码 |
| type | 否 | 产品类型，可选。代码无歧义时无需传递；若返回 `AMBIGUOUS_SYMBOL` 错误，按提示传入对应值即可。可选值：`stock`、`indices`、`crypto`、`forex`、`futures` |

## 返回字段说明

| 字段 | 说明 |
|------|------|
| symbol | 交易产品 |
| type | 产品类型 |
| timestamp | 数据时间戳（毫秒，UTC） |
| bids | 买盘数组，每个元素为 [价格, 数量] |
| asks | 卖盘数组，每个元素为 [价格, 数量] |
