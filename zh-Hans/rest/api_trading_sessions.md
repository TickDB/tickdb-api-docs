---
title: 交易时段
description: 查询一个或全部支持市场的交易时段信息，包括开盘时间、收盘时间等。
openapi: "openapi.yaml GET /v1/market/trading-sessions"
contextual:
  options:
    - copy
    - view
---

## 套餐权限

| 套餐 | 可用 |
|---|:---:|
| 免费版 | ✅ |
| 基础版 | ✅ |
| 专业版 | ✅ |
| 全量套餐（A 股、港股、美股） | ✅ |
| 企业版 | ✅ |

## 注意事项
- 返回的时间为各市场的**当地时间**

## 支持的市场

| 市场 | 示例 |
|---|---|
| 美股 | US |
| 港股 | HK |
| A股 | CN |

## 请求参数

| 参数名 | 是否必须 | 描述 |
|--------|----------|------|
| market | 否 | 市场代码，可选值：`US`、`HK`、`CN`；不传时返回全部支持市场 |

## 返回字段说明

| 字段 | 说明 |
|------|------|
| market | 市场（US - 美股市场，HK - 港股市场，CN - A股市场） |
| trading_sessions | 交易时段数组 |
| └─ begin_time | 交易开始时间，格式：hhmm，例如：900 |
| └─ end_time | 交易结束时间，格式：hhmm，例如：1400 |
| └─ trade_session | 交易时段类型（0 - 盘中交易，1 - 盘前交易，2 - 盘后交易，3 - 夜盘交易） |
