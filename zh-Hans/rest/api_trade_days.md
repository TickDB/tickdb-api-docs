---
title: 交易日历
description: 查询指定市场在特定时间范围内的交易日列表，用于判断某日是否为交易日。
openapi: "openapi.yaml GET /v1/market/trade-days"
contextual:
  options:
    - copy
    - view
---

## 套餐权限

| 套餐 | 可用 |
|---|:---:|
| 免费版 | ✅ |
| 基础版 | ✅ |
| 专业版 | ✅ |
| 全量套餐（A 股、港股、美股） | ✅ |
| 企业版 | ✅ |

## 注意事项
- 日期格式必须为 YYYYMMDD（如：20260201）
- 单次查询的日期范围最多为 31 天
- 开始日期必须在最近一年范围内
- 返回的交易日不包括周末和节假日
- 市场代码不区分大小写

## 支持的市场

| 市场 | 示例 |
|---|---|
| 美股 | US |
| 港股 | HK |
| A股 | CN |

## 请求参数

| 参数名 | 是否必须 | 描述 |
|--------|----------|------|
| market | 是 | 市场代码，可选值：`US`、`HK`、`CN` |
| beg_day | 是 | 开始日期，格式：YYYYMMDD，必须在最近一年范围内 |
| end_day | 是 | 结束日期，格式：YYYYMMDD；与开始日期的范围最多为 31 天 |

## 返回字段说明

| 字段 | 说明 |
|------|------|
| market | 市场代码 |
| trade_days | 全日交易日列表，使用 YYYYMMDD 格式 |
| half_trade_days | 半日交易日列表（仅半天交易），使用 YYYYMMDD 格式 |
