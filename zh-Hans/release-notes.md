## v1.0.3 (2026-09-21)

### 新增功能

- 新增财务与基本面接口文档，覆盖公司概况、主营构成、财务报表、估值与行业、分红与公司行动、股东与机构持仓、市场资讯与日历。
- 新增 A 股、港股和美股全量行情：REST API 单次请求可获取指定市场的完整行情快照，WebSocket 单次订阅可持续接收该市场全部标的的实时行情更新。
- 新增 K 线复权因子接口及 JavaScript 计算示例，适用于基于不复权 K 线动态生成前复权或后复权数据。
- 增加对香港股票期货和金融期货的支持。

## v1.0.2 (2026-07-16)

### 新增功能

- 产品查询、REST 行情接口和 WebSocket 频道新增中国期货支持，产品类型使用 `type=futures`。
- 新增期货持仓相关字段：K 线 `open_interest`，成交数据 `open_interest_change` 和 `position_effect`。

## v1.0.1 (2026-03-13)

### 新增功能

- **新增股票市场专属接口**

  - 股票详细信息接口
  - 交易时段查询接口
  - 交易日历查询接口
  - 市场指标数据接口
  - 资金流向数据接口

### 重要改进

- **WebSocket 文档重构**
  - 新增 ping/pong 心跳机制说明
  - 更新 ticker 频道消息格式（按市场类型区分字段）
  - 修正 trade 频道响应格式（包含 trades 数组）
  - depth 频道新增 A 股支持

- **文档内容优化**
  - 重新组织 REST API 导航结构
  - 完善所有接口的请求参数和返回字段说明
  - 更新支持市场标注和示例
  - 统一术语翻译
  - 优化入门指南和数据规范

## v1.0.0 (2026-01-15)

### 首次发布

提供核心 REST API 和 WebSocket 实时订阅，覆盖外汇、贵金属、指数、美股、港股、A 股、加密货币市场。

- **REST API 接口**
  - 交易品种查询
  - 行情快照
  - K 线查询
  - 实时 K 线
  - 订单簿
  - 最近成交
  - K 线周期查询

- **WebSocket 频道**
  - ticker 频道
  - depth 频道
  - trade 频道
